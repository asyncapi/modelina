# Generate Kotlin models with Jackson support

This example shows how to use `KOTLIN_JACKSON_PRESET` to add Jackson annotations for JSON serialization and deserialization to generated Kotlin data classes and enums.

## How to run this example

Run this example using:

```sh
npm i && npm run start
```

If you are on Windows, use the `start:windows` script instead:

```sh
npm i && npm run start:windows
```
